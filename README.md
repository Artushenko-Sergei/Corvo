# Corvo

**WhatsApp на рабочем столе Linux.** Обычное окно программы вместо вкладки в
браузере: значок в трее со счётчиком непрочитанных, системные уведомления,
видеозвонки, автозапуск. Вход по QR-коду — один раз.

### [⬇ Скачать для Debian и Ubuntu](https://github.com/Artushenko-Sergei/Corvo/releases/latest)

Один файл, ставится одной командой — [как установить](#установка).

## Зачем это нужно

* **Не теряется среди вкладок.** Отдельное окно, свой значок в панели задач, Alt-Tab.
* **Уведомления как у обычной программы** — системные, с именем и текстом; клик открывает нужный чат.
* **Значок в трее** показывает число непрочитанных. Закрытие окна сворачивает в трей, программа продолжает получать сообщения.
* **Звонки работают** — видео и голос, без сообщения «браузер не поддерживает функцию звонков».
* **Вход один раз.** Сессия сохраняется, QR-код при каждом запуске не нужен.
* **Автозапуск** при входе в систему, можно сразу свёрнутым в трей.
* **Язык интерфейса сам подстраивается** под язык вашего WhatsApp: русский, английский, немецкий, украинский.
* **Ничего лишнего:** нет рекламы, нет сбора статистики, нет своих серверов. Программа общается только с `web.whatsapp.com`.

## Установка

Готовый файл лежит на странице
[Releases](https://github.com/Artushenko-Sergei/Corvo/releases/latest) — в списке
файлов внизу, называется `corvo_<версия>_amd64.deb`. В самом дереве проекта его
нет: там исходный код.

**Debian, Ubuntu, Mint и другие системы с `apt`** — скачайте файл и поставьте:

```bash
sudo apt install ~/Загрузки/corvo_*_amd64.deb
```

Ничего доустанавливать не нужно, всё необходимое уже внутри. Программа появится
в меню приложений под именем **Corvo**.

Обновление — тем же способом, поверх: `apt` заменит старую версию. Удаление:

```bash
sudo apt remove corvo
```

| Требуется | |
|---|---|
| Система | Debian 12+, Ubuntu 22.04+ или производная, 64-битная (amd64) |
| Графика | X11 или Wayland — работает и там, и там |
| Звук | PipeWire или PulseAudio (в большинстве систем уже есть) |
| Место на диске | около 350 МБ |

Проверено на Debian 12 с KDE, в сеансах Wayland и X11.

**Flatpak / Flathub** — пакет собран и проходит проверки Flathub, публикация
готовится. Появится команда `flatpak install flathub io.github.artushenko_sergei.Corvo`.

**Сборка из исходников** — см. [docs/DEVELOPMENT.md](docs/DEVELOPMENT.md).

## Первый запуск

1. Откройте Corvo — появится QR-код.
2. На телефоне: **WhatsApp → Настройки → Связанные устройства → Привязка устройства**.
3. Наведите камеру на QR-код. Чаты загрузятся сами.

Больше сканировать не придётся: пока телефон остаётся привязанным, программа
помнит вход. WhatsApp сам разорвёт связь, если телефон не появлялся в сети
несколько недель — тогда просто отсканируйте код снова.

## Как этим пользоваться

**Трей.** Левый клик по значку — показать или скрыть окно. Правый — меню: показать,
свернуть, перезагрузить, проверка камеры, настройки, выход. Пока значок в трее
есть, закрытие окна не выключает программу; чтобы выйти — «Файл → Выход» или
пункт «Выход» в меню трея.

**Настройки** (`Файл → Настройки`): автозапуск, свёрнутый старт, уведомления,
масштаб интерфейса, язык, добавление ярлыка в меню приложений и проверка камеры
с микрофоном.

**Проверка камеры и микрофона** — если WhatsApp не видит камеру, откройте
«Настройки → Проверить камеру и микрофон». Диалог покажет список устройств, живой
предпросмотр камеры и индикатор уровня микрофона. Проверка идёт через тот же
движок, что и WhatsApp, поэтому её результат совпадает с тем, что видит сайт.

**Язык.** По умолчанию интерфейс говорит на языке вашего WhatsApp — а он приходит
с телефона, у WhatsApp Web своей настройки языка нет. Если хотите иначе, в
настройках можно выбрать язык принудительно.

## Ваши данные

Corvo не имеет своих серверов и ничего никуда не отправляет: переписка идёт
напрямую между вашим компьютером и WhatsApp, ровно как в браузере. Всё, что
программа хранит, лежит у вас:

| Что | Где |
|---|---|
| Сессия WhatsApp (вход, кэш чатов) | `~/.local/share/Corvo/profile/` |
| Настройки | `~/.config/Corvo/Corvo.conf` |
| Журнал работы (для диагностики) | `~/.local/share/Corvo/logs/` |

Полностью удалить все следы — включая вход:

```bash
rm -rf ~/.local/share/Corvo ~/.config/Corvo
```

Заодно зайдите на телефоне в «Связанные устройства» и отвяжите компьютер.

## Если что-то не работает

| Проблема | Что делать |
|---|---|
| Просит QR-код при каждом запуске | Проверьте, что домашний каталог не переполнен и доступен для записи |
| Нет уведомлений | Включите их в настройках; в GNOME/KDE должен работать штатный центр уведомлений |
| Нет значка в трее | В GNOME нужно расширение AppIndicator. Без трея закрытие окна завершает программу |
| Камера не найдена | «Настройки → Проверить камеру и микрофон». Если устройств нет и там — проблема в системе, а не в программе: проверьте, что камера не занята другой программой |
| Нет звука в звонке | Проверьте громкость и выбор устройства в системном микшере — Corvo использует системный звук |
| Не работает демонстрация экрана | Нужен установленный `xdg-desktop-portal` для вашей среды |

Если проблема осталась — [откройте issue](https://github.com/Artushenko-Sergei/Corvo/issues)
и приложите последние строки из `~/.local/share/Corvo/logs/Corvo.log`.
